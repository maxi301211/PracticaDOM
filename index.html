Practica DOM

Introducción al DOM con JavaScript

El DOM es una representación del HTML como objetos de JavaScript. Nos permite modificar elementos en la pagina mientras se ejecuta

Seleccion de elementos

Metodos del elemeneto document

  • getElementById('id') -> selecciona por ID
  • getElementByClassName('clase') -> selecciona por clase
  • getElementByTagname('tag') -> devuelve por tipo de etiquetas
  • querySelector('tag') -> devuelve el primer elemento que coincide
  • querySelectorAll('selector') -> devuelve todos los que coinciden

Modificar contenido

  • textContent agrega un texto plano (más seguro)
  • innerHTML interpreta HTML (vulnerable a xss si no se controla)

Manipular clases con classList

classList es una propiedad de los elementos DOM que permite trabajar facilmente con las clases CSS. Dvuelve un objeto con metodos utiles
